# بورتفوليو أحمد تهامي — نسخة محلية كاملة

الموقع ده هو قالب التصميم الأصلي بعد ما اتحوّل بالكامل لمحتوى **أحمد تهامي** (مهندس برمجيات — مطور Flutter أول)
بناءً على `cv.latex` وصور مشاريع `oldporto` والصورة الشخصية `me.png`.

## إزاي تشغّله

دوس دبل كليك على:

```
start-server.bat
```

هيبدأ السيرفر ويفتح المتصفح على <http://localhost:4743>

أو من التيرمنال:

```bash
node server.mjs
```

لتغيير البورت: `set PORT=5000 && node server.mjs`

> مهم: الموقع لازم يفتح من خلال السيرفر (http://localhost:4743) ومش بالدبل كليك على `index.html`،
> لأن Next.js بيحمّل ملفاته من مسارات جذرية زي `/_next/...`.

## ملاحظات تقنية

1. محتوى الأقسام متكرر في **الـ HTML** و**ملفات الـ JS**؛ أي تعديل لازم يتم في الاتنين
   وإلا الـ hydration هيعمل mismatch.
2. ملفات `_next/*` اتعدّلت في مكانها مع احتفاظها بنفس الاسم، فمهم إنها تتبعت بـ `no-cache`
   (زي ما `server.mjs` بيعمل دلوقتي لملفات JS/CSS) بدل `immutable` — وإلا الزائر اللي فتح
   الموقع قبل التعديل يفضل شايف نسخة قديمة (زي اسم/نافيجيشن قديم) بعد الـ hydration.
   على أي استضافة ستاتيك تانية لازم تعمل نفس الهيدرز أو Hard Reload مرة واحدة.
   وملفات الطبقات المخصّصة (`tohamy-*.js/css`, `profile-layer.js`) كل تعديل بياخد `?v=` جديد في وسوم الـ HTML.
3. سيرفر Next محلي بيرجّع `index.rsc` مع `?_rsc=` عشان التنقل الداخلي يشتغل بدون نت.
4. `_backup_original/` فيه نسخة من الملفات قبل التخصيص لو احتجت ترجّع أي حاجة.
5. `profile-layer.js` بيشتغل بعد الـ hydration ويضيف العناصر بره شجرة React عشان مايحصلش mismatch.
   وكل الطبقات المخصّصة (`tohamy-popup`, `tohamy-theme`, `profile-layer`, `tohamy-polish`) بتمر على
   `tohamy-ready.js` قبل أي إضافة DOM — لأن React هنا بيهيدريت الـ `document` كله، وأي عنصر
   بيتضاف أثناء الهيدريشن بيرجّع الخطأ `#418` ويعيد رسم الصفحة.
6. الـ CV page صفحة ستاتيك مستقلة بتستخدم نفس خطوط وألوان الموقع، وليها `@media print` لو احتجت تطبعها.
7. حروف `TOHAMY` في `brand/letters` مصدرها مشهد Blender في `_tools/letters/render_blender.py`:
   بلاطة مكعبة بحواف bevel، وإضاءة studio HDR + 4 area lights، وحروف Baloo 2 ExtraBold
   بارزة مع remesh/smooth. الرندر 1024×1024 بخلفية شفافة، وبعدها `prep_blender.py` بيقصّ
   ويضيف الحواف ويطلع WebP 512×512. الألوان بتبديل صارم زي المرجع: T/H/M بلاطة سوداء +
   حرف كريمي، وO/A/Y بلاطة أزرق زجاجي + حرف برتقالي.
   لتوليد جديد: `set STUDIO_HDR=<path>\studio.hdr` ثم
   `blender -b -P _tools/letters/render_blender.py -- <outdir> 64 1024` ثم
   `python _tools/letters/prep_blender.py <outdir> brand/letters --backup`.
   ولأن الصور بتتخدم بـ `immutable`، أي توليد جديد لازم يغيّر `?v=` في `index.html`
   و`en/index.html` **وكمان** في الـ chunks اللي بتبني `src`
   (`201ts4f0eubt2.js` و`201ts4f0eubt2b.js`) عشان الـ hydration مايعملش mismatch.
   (`generate.mjs` نسخة SVG بديلة/تجريبية، ومش مصدر الصور الحالية.)
8. أيقونات الأدوات في `brand/technologies` شعارات رسمية (Simple Icons لـ Flutter/Dart/Kotlin/Firebase/MQTT/
   React/Laravel/PostgreSQL/MySQL/Next.js وشعار BLoC الرسمي)، وبتظهر أبيض داخل بلاطات ملوّنة عبر
   `filter: brightness(0) invert(1)` زي المرجع. مجلد الأدوات بقى فيه 11 أداة: الـ fan بيتكثّف تلقائيًا
   (زاوية دوران وarc أقل للأعداد الكبيرة)، و`tohamy-polish.css` بيضغط شرائح الأسماء ويخفي شريط الأيقونات
   الصغير أسفل المجلد عشان مايتعارضش مع آخر صف شرائح. أي تحديث لأيقونة لازم ياخد `?v=` جديد في
   `index.html` و`en/index.html` **وكمان** في الـ chunks اللي بتبني `src`
   (`201ts4f0eubt2.js` و`201ts4f0eubt2b.js`). تغيير `tohamy-polish.css` نفسه بيتطلب bump
   لـ `?v=` في الصفحتين.

## إصلاحات وتحسينات نوفمبر 2026

### أخطاء اتصلحت

1. **كسر الـ hydration في النسختين:** الـ HTML كان فيه هيدر `أنا` بدل `tohamy` (النسخة العربية)،
   وجملة الإنجليزية كانت مقلوبة (`websites`/`apps`)، وكمان مجلدين من المشاريع + `continuation`
   كانوا متحركين بره `main`. React كان بيرمي `#418` ويعيد رسم الشجرة بالكامل — اتصلح الهيكل
   والمحتوى في `index.html` و`en/index.html`.
2. **سباق الهيدريشن في الطبقات:** إضافات `profile-layer` كانت بتدخل `.contact-socials` قبل ما
   React يخلص، فترجّع نفس الخطأ. اتعمل `tohamy-ready.js` كبوابة موحّدة، وكل الطبقات بقت تستناها
   مع إعادة محاولة خفيفة بعد الـ commit.
3. **Deadlock في مشهد «ليه نضيع وقت؟»:** المشهد بيعمل scroll-lock لمدة ~7 ثواني عشان الأنيميشن،
   وأي انتقال سريع للتواصل كان بيتعلّق في نص الطريق. دلوقتي زر «تواصل معايا» وروابط `#contact`
   بيفكّوا القفل وينتقلوا للفورم فورًا (مع إعادة تثبيت الكونتاكت لو المستخدم بيتصفح طبيعي).
4. **الوصولية:** زر كتم الرنّة كان `tabindex="-1"` و11×11px — بقى قابل للوصول وبمساحة لمس 44px،
   وأيقونات الأزرار والروابط بقت بحلقة تركيز واضحة، والـ dialog بقى `aria-modal` + `inert`
   للخلفية + ربط التركيز + `aria-expanded` متزامن مع الفتح/الإغلاق.
5. **زر إرسال الفورم بيتقطع على الشاشات القصيرة:** القفز لـ«كلّمني» كان بيروح لآخر الصفحة،
   فالفوتر بيزحّ البانل لأعلى (الـ sticky stage بيتقفل) وزر «يلا نتكلّم» بيتقطع تحت الفوتر
   والكليك عليه بيضرب عنصر تاني. دلوقتي القفز بيقف عند آخر وضع مثبّت للبانل كامل في الشاشة،
   و`tohamy-polish.css` بيضغط المسافات عموديًا لما الارتفاع ≤ 800px، ولو المحتوى لسه أطول
   بيتظبط سكرول البانل الداخلي لحد ما الزر يبان.

### إضافات UX/UI

- **Dock عائم** (نهاية الاتجاه): تبديل الوضع الفاتح/الداكن (محفوظ في `localStorage`)،
  «تواصل معايا»، وزر رجوع لفوق بحلقة تقدّم.
- **هيدر ذكي:** يتحول لزجاج على الاسكرول ويختفي لتحت ويرجع مع أول حركة لفوق، مع مؤشر
  قسم نشط في قائمة الأيقونات.
- **تنقل سريع:** الانتقال للأقسام في ~0.5–0.9 ثانية بدل ما كان ممكن ياخد 10+ ثواني،
  مع `scroll-spy` و`aria-current`.
- **فورم التواصل:** تحقق مباشر برسائل عربية/إنجليزية، عدّاد أحرف، حالة «بنجهّز الإيميل…»،
  Toast احتياطي لو تطبيق الإيميل مافتحش، وزرار نسخ الإيميل. ولو المتصفح رفض الكتابة على
  الـ clipboard بيتحدد الإيميل نفسه تلقائيًا مع رسالة توضّح إن `Ctrl+C` جاهز.
- **مجلدات المشاريع:** Overlay بستايل أرقى (زجاج فاتح + نحاسي)، Bottom-sheet على الموبايل
  مع Drag-to-close، صور تدخل بـ fade، شارة «تفاصيل خاصة» للمشاريع غير المنشورة، وفتح
  الكروت الخاصة بيوديك مباشرة للتواصل بدل تاب جديد فاضي.
- **الصقل الحركي:** Sheen على المجلدات والأزرار، رفع/ظل ناعم، Reveal تدريجي لصفحات
  السيرة الذاتية، واحترام كامل لـ `prefers-reduced-motion`.
- **ألوان أفضل:** تفتيح/تغميق بعض النصوص الواطية (وصف القدرات، الإيميل، سوشيال،
  Eyebrow) لتخطي تباين AA، مع الحفاظ على هوية Obsidian & Copper.

## التحقق

اتعمل فحص في متصفح حقيقي على النسختين العربية والإنجليزية:

- الـ hydration شغال (المجلدات بتفتح، فيديوهات الـ intro بتشتغل، فورم التواصل بيفتح الإيميل).
- 0 صور مكسورة (12 غلاف مشروع + 6 أيقونات أدوات + البورتريه + المونوجرام).
- البورتريه بخلفية شفافة ومقاسه محفوظ (1109×1245) بدون تشويه، وشغال على 390×844 و1440×1000.
- روابط CV/PDF ظاهرة في التواصل على النسختين.
- صفحتي `/cv/` و`/en/cv/` متوافقتين على الموبايل والديسكتوب.
- مفيش overflow أفقي على موبايل 390×844 ولا على الديسكتوب.
